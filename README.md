# Geological Assay Periodic Table Series Hub

An interactive directory of seven geological assay and analytical-method reference pages. The hub includes embedded JPEG previews and links to the standalone projects.

## Run locally

Open [`index.html`](index.html) in a modern browser. The previews are embedded in the page; the seven analytical pages are maintained in separate repositories linked from the hub.

- [Major and Refractory Elements](https://github.com/MohamedMahmoudElSayed/03-major-refractory-periodic-table)
- [Base Metals and Pathfinders](https://github.com/MohamedMahmoudElSayed/04-base-metals-pathfinders-periodic-table)

- [Halogens and Isotopes](https://github.com/MohamedMahmoudElSayed/07-specialized-halogens-isotopes-periodic-table)
